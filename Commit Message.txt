Seller listing form: fix section behavior and scroll jumping

- All form sections (Product, Packaging, Pricing, Fulfilment, Terms,
  Delivery) now start closed when the seller opens the page, instead
  of "Product" being open by default — cleaner, less overwhelming
  first impression.

- Fixed an issue where opening one section while another was already
  open caused the screen to visually "jump" to a random spot, making
  it look broken or glitchy. Now, when a seller opens a new section,
  the page smoothly scrolls so that section starts right at the top
  of the screen, then they can scroll down through it normally.

- Fixed a crash bug introduced while building the above fix — the
  scroll code was referencing values that didn't actually exist,
  which would have made the app throw an error every single time a
  seller tried to open any section. Caught and fixed before it could
  reach production.

- Refined the scroll behavior further: the page now only auto-scrolls
  when the newly opened section is actually too big to fit on screen
  as-is. If the section already fits fine where it is, the page
  leaves it alone instead of scrolling unnecessarily — feels much
  less "jumpy" and more natural to use.

- Reworked how columns behave so each one grows independently — opening a seller list for one product only pushes down items in that same column, without shifting or disturbing products in other columns

Seller listings page: rename to "My Products" + add wallet access

- Renamed the seller's listings page from a plain heading to "My
  Products" — a clearer, friendlier name for what the seller actually
  sees there.

- Added a wallet balance card right at the top of "My Products", so
  sellers can see how many credits they have left at a glance without
  needing to visit a separate page.

- Tapping the wallet card takes the seller straight to the full Wallet
  page (unchanged) — so all the existing wallet features (adding
  credits, payment history, transaction ledger) still work exactly as
  before, just easier to reach.

- If a seller's account is blocked due to low/zero balance, the wallet
  card turns red and clearly says "Orders paused" instead of just
  showing a balance — so the reason new orders have stopped is obvious
  right from the main listings screen.

- Polished the page header multiple times based on feedback — made the
  "My Products" title bolder and more prominent, gave the wallet card
  a proper visual design matching the rest of the app (rounded card
  with icon, colored background, tap-to-open arrow), and fixed it so
  the title and wallet balance sit neatly side-by-side on both mobile
  and desktop instead of looking cramped or oddly stacked on phones.
